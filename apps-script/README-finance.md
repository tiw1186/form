# วิธีเชื่อมระบบบันทึกเงินคงเหลือประจำวัน (/finance-record) เข้ากับ Google Sheet

ระบบนี้ใช้สเปรดชีตเดียวกันสองส่วน:

- **gid=0** — ชีตรายชื่อโรงเรียน (คอลัมน์หัวข้อ `รายชื่อโรงเรียน`) ใช้แสดงในแถบค้นหา/เลือกโรงเรียน
- **gid=1035907838** — ชีตบันทึกเงินคงเหลือประจำวัน ที่ระบบจะเขียนแถวข้อมูลใหม่ทุกครั้งที่กด "บันทึกข้อมูล"

สเปรดชีต: https://docs.google.com/spreadsheets/d/1-QguwE2O91dK9f5dxW_S49p3CpmDnzCFg80KvY9eUPc/edit

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

1. เปิดสเปรดชีตด้านบน
2. เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดตัวอย่างเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `apps-script/FinanceCode.gs` ลงไปแทน
4. กด **บันทึกโปรเจกต์** (ไอคอนแผ่นดิสก์)
5. กด **Deploy > New deployment**
6. ที่ "Select type" กดไอคอนเฟือง เลือก **Web app**
7. ตั้งค่า:
   - Execute as: **Me (อีเมลของคุณ)**
   - Who has access: **Anyone**
8. กด **Deploy** แล้วอนุญาต (Authorize) สิทธิ์การเข้าถึงตามที่ Google ขอ
9. คัดลอก **Web app URL** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)
10. นำ URL ไปวางแทนที่ `PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE`
    ที่ค่า `GOOGLE_FINANCE_WEBAPP_URL` ในไฟล์ `src/config.js` ของโปรเจกต์ Vue
11. บันทึกไฟล์ แล้วรัน/build โปรเจกต์ใหม่ (`npm run serve` หรือ `npm run build`)

เมื่อผู้ใช้เปิดหน้า `/finance-record` ระบบจะเรียก Web App (`?action=schools`) เพื่อโหลดรายชื่อโรงเรียน
มาแสดงในแถบค้นหา และเมื่อกด **บันทึกข้อมูล** ข้อมูลจะถูกส่งไปเขียนเป็นแถวใหม่ในชีต
`บันทึกเงินคงเหลือประจำวัน` (gid=1035907838) โดยอัตโนมัติ (สร้างหัวตารางให้เองถ้ายังไม่มี)

## หมายเหตุ

- ถ้ายังไม่ได้ตั้งค่า `GOOGLE_FINANCE_WEBAPP_URL` หน้าเว็บจะพยายามโหลดรายชื่อโรงเรียนจากไฟล์ CSV
  สาธารณะของชีตแทน (ต้องแชร์สเปรดชีตเป็น "ทุกคนที่มีลิงก์ดูได้") และเมื่อกดบันทึกจะดาวน์โหลดข้อมูล
  เป็นไฟล์ `.json` ให้แทน เพื่อไม่ให้ข้อมูลหาย — แนะนำให้ตั้งค่า Web App URL เพื่อการทำงานที่สมบูรณ์
- ถ้าภายหลังแก้โค้ดใน Apps Script ต้องกด **Deploy > Manage deployments > แก้ไข (ไอคอนดินสอ) >
  เปลี่ยน Version เป็น New version > Deploy** ทุกครั้ง ไม่เช่นนั้นการแก้ไขจะไม่มีผล
- หากหัวคอลัมน์รายชื่อโรงเรียนในชีต gid=0 ไม่ได้ชื่อว่า `รายชื่อโรงเรียน` พอดี ให้แก้ชื่อหัวคอลัมน์
  ให้ตรงกัน มิฉะนั้นระบบจะอ่านจากคอลัมน์แรกแทน
